On-device

The Whisper speech model runs on your own hardware. First use downloads it once (~40 MB); after that it works with no connection at all.

Private by design

Audio is processed locally and discarded when it's done. Nothing is uploaded, logged, or sent to a third party — there's no backend to send it to.

VoiceFlow uses a custom-tuned Whisper model optimized for dictation speed. The on-device pipeline resamples to 16 kHz mono, transcribes in real-time, and pipes the result straight into any app — no microphone settings page required.

  • 16 kHz mono — optimized sample rate for Whisper tiny.en
  • Auto-detect voice — records only when you speak, silences are skipped
  • Global shortcut — ⌘⇧V (macOS) / Ctrl+Shift+V (Windows) from anywhere
  • Streaming mode — optional Groq API for sub-second latency
  • Smart editing — filler-word removal and auto-formatting built in

How it works

Three steps, all of them local.

  1. Press and speak Your microphone is captured in the page — no recording is saved to disk.
  2. Transcribed locally Whisper runs in WebAssembly on your device and turns the audio into text.
  3. Text, instantly Copy it here. In the desktop app it types straight into whatever you're using.

Don't take our word for it — open your browser's Network tab and dictate. You'll see zero requests.

Add dictation to your own site

One script tag drops a floating dictation button onto any page. It uses the same on-device Whisper pipeline — audio is transcribed in the visitor's browser and never sent anywhere.

  1. Host this Website/ folder (after running setup) on your domain.
  2. Paste the snippet before </body> on any page.
  3. A dictation button appears in the corner — tap, speak, copy.

If the model assets aren't hosted alongside the script, the button shows a friendly setup message instead of failing.

embed snippet 
<!-- VoiceFlow dictation — paste before </body>. Runs on-device; no server. -->
<script>
  window.VOICEFLOW_CONFIG = {
    position: "bottom-right",  // or "bottom-left"
    title: "Dictate",
    theme: "auto"              // "auto" | "dark" | "light"
  };
</script>
<script src="/embed/voiceflow-embed.js" defer></script>
