VoiceFlow Embed Widget

Test page demonstrating cross-origin, iframe, mobile, and CSP scenarios

1. Basic Embed (Same-Origin)

Standard usage with assets hosted alongside the script.

// Configure before loading the script window.VOICEFLOW_CONFIG = { position: "bottom-right", title: "Dictate", theme: "auto" };
Same-Origin Desktop Mobile

The widget below loads from /embed/voiceflow-embed.js with relative asset paths.

2. Cross-Origin Embed (CDN Assets)

Embed on any domain by pointing to absolute asset URLs.

// Configure with absolute assets URL window.VOICEFLOW_CONFIG = { assetsUrl: "https://cdn.example.com/voiceflow/", allowedOrigins: ["https://your-site.com", "https://another-site.com"], nonce: "csp-nonce-value" };
Cross-Origin CSP Compatible CDN Assets

Use assetsUrl (or baseUrl) for CDN-hosted assets. allowedOrigins enables secure postMessage.

3. Iframe Embed (Sandboxed)

Load widget in a sandboxed iframe with microphone and clipboard permissions.

// Parent page config window.VOICEFLOW_CONFIG = { assetsUrl: "https://cdn.example.com/voiceflow/", allowedOrigins: ["https://parent-site.com"] };
Iframe Sandbox Microphone Access Clipboard Access

Iframe requires allow="microphone; clipboard-write; clipboard-read"

4. Mobile Responsive (Bottom Sheet)

On viewports ≤480px, the panel becomes a full-width bottom sheet.

Mobile ≤480px Bottom Sheet Touch Optimized

5. CSP Strict Mode (nonce + strict-dynamic)

Works with strict CSP policies using nonce-based style injection.

// CSP header example Content-Security-Policy: default-src 'self'; script-src 'nonce-{RANDOM}' 'strict-dynamic'; style-src 'nonce-{RANDOM}'; connect-src 'self' https://cdn.example.com; media-src 'self' blob:; worker-src 'self' blob:;
// Embed with nonce window.VOICEFLOW_CONFIG = { nonce: "{RANDOM_NONCE}", assetsUrl: "https://cdn.example.com/voiceflow/" };
CSP Nonce strict-dynamic No Inline Styles

The widget injects styles via style.textContent with the provided nonce. No inline scripts.

6. Error States & Guidance

Actionable error messages when assets aren't installed.

Missing Assets Clear Instructions CDN Config Help

When assetsUrl isn't configured and same-origin assets are missing, the widget shows setup instructions with your exact expected paths.

Example error message:
On-device model not installed.
Configure VOICEFLOW_CONFIG.assetsUrl with the absolute URL to your VoiceFlow assets.
Example: window.VOICEFLOW_CONFIG = { assetsUrl: "https://cdn.example.com/voiceflow/" }
